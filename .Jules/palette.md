## 2026-07-26 - Keyboard Focus and Accessibility Enhancements
**Learning:** Modern web application designs frequently use custom styled containers to wrap interactive elements like file inputs. Simply using the `hidden` class on the native elements completely breaks their keyboard accessibility and focus capabilities. Utilizing utilities like Tailwind's `sr-only` keeps the element interactive and available to screen readers while allowing focus states to bubble up to custom wrappers through the `focus-within` selector. Additionally, icon-only buttons require descriptive `aria-label` tags and visible focus rings to be accessible to assistive technologies and keyboard users.
**Action:** When working with file inputs or custom interactive elements, always replace `hidden` with `sr-only` and bubble up focus states with `focus-within:`. Always add `aria-label` and `focus-visible:` outlines to icon-only buttons.
